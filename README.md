# Docu: sistema de expedientes médicos

Este sistema es comercial y está destinado a médicos y profecionales de la salud de otras áreas que necesitan llevar un registro de pacientes.

## Campos

El sistema base permite la incorporación de los siguientes campos:

- Paciente: Incluye los datos personales
- Laboratorios: Incluye varios archivos que se almacenan en local pero se guardan la referencia
- Consulta
  - Controles
  - Diagnosticos
  - Tratamientos
- Antecedentes
  - Vacunas
  - Alergias
  - Cirugías
  - Enfermedades
    - Relación familiar

## Modo de edición

Para editar el programa se ejecutan los comandos:

- npm run dev
- npm run dev:electron
- npm run dev:react
